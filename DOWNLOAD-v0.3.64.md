# Miniopoly v0.3.64 — Police car and School bus

- [Cumulative update for a complete v0.3.59–v0.3.63 game](downloads/v0.3.64/Miniopoly-v0.3.64-Update.zip?raw=true).
- [Complete game ZIP](downloads/v0.3.64/Miniopoly-v0.3.64-Complete.zip?raw=true).
- [SHA-256 checksums](downloads/v0.3.64/SHA256SUMS.txt).

If GitHub opens a file page, choose Download raw file. This branch also contains
the current game at its top level, so Code > Download ZIP supplies v0.3.64.

Stop hosting and fully Exit Launcher from the Windows tray before updating.
Extract the update into your existing complete game folder containing server.js
and replace matching files, or extract the Complete ZIP into a new folder.
Launch from the updated folder, start hosting and refresh every browser.
Confirm v0.3.64. Restarting the host is required for the new School bus option.

Car becomes Police car automatically, preserving saved selections. School bus
is a new selectable piece. Both include the approved movement and arrival effects.
Monster truck remains excluded. See [UPDATE-v0.3.64.md](UPDATE-v0.3.64.md).
