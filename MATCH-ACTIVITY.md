# Match Activity window

During a match, Match Activity is a compact floating window on the left rather
than a full-width row below the board. Its default desktop size is about
290 × 186px; phones use a narrower window. The full recent history remains
scrollable inside it.

- Drag the **Match activity** header to move the window with a mouse or touch.
- Focus that header and use arrow keys to move 10px, or Shift + arrow for 40px.
- Press **−** to minimize to its header, and **+** to restore. Escape minimizes
  when focus is inside the window.
- Press **↺** to reset its placement to the left.
- Game Menu → Results & activity → Match activity restores and focuses the log.

Placement is remembered separately for desktop and phone layouts. Minimized
state is remembered in this browser; new activity does not reopen the window.
The window stays within the visible viewport on resize, zoom and short screens.
If there is room, its default position is below the left Quick Actions panel;
on a short desktop window it starts just beside that panel to keep its buttons
reachable. The history's reading position is retained when possible as new
entries arrive while minimized.

Chat has its own controls and saved position. The activity window hides while
Game Menu is open. Before a match starts, the lobby's activity remains in the
menu rather than opening a floating window. Existing rules, saved rooms, turns,
trading, portals and ember fees are retained.
