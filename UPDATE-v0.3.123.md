# Miniopoly v0.3.123

Robot messages now appear in a cream chatbox below the game board, with the bot illustration at the left. The follow/stop-following and Bot voice controls are in the same panel. Messages and controls no longer cover the neighborhood name, die or cards in the board center.

The box scrolls independently with mouse, touch or keyboard. It follows incoming messages while you are at the bottom; if you scroll back, it preserves your reading position and offers a New messages shortcut. Up to 500 robot messages are retained per saved match and survive host restarts. Recent older-save announcements are imported as new history begins; player chat remains separate. Starting another match clears the previous match's visible robot log.

Desktop layout reserves space for the bottom panel and keeps the whole board visible. Phones keep the full-width board with the log below it. Optional bot speech and arrival sounds still respect personal Sound settings.

This is a cumulative update. Fully Exit Game, extract the Update ZIP into your existing complete game folder and replace files. Restart the host and refresh every player. Confirm v0.3.123. Existing saves continue.
