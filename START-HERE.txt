# Miniopoly v0.3.119

Saved games now appear most recently played first in Game Launcher for both the host and player saved-seat lists. Resuming a saved game moves it to the top, and that ordering survives restarting the host. Older saves without a timestamp retain their relative order at the bottom.

This is a cumulative update, including v0.3.118 property condition and cleaning house calls. Fully Exit Game, extract the Update ZIP into the existing complete game folder and replace files. Restart the host and refresh every player. Confirm v0.3.119.
