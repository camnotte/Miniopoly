MINIOPOLY v0.3.71 - SEPARATE GAME OPTIONS

Stop hosting and fully Exit Launcher from the Windows system tray.
Apply the update over your complete game folder, or extract Complete into a new
folder. Relaunch, refresh every browser and confirm v0.3.71.
Existing rooms and seats can resume.

Create / Join contains your identity, avatar and game piece.
The separate Game Options window has three mode rows with rounds beside each:
Standard (the existing Classic mode), World Collapse and Countdown.
Additional options: room size, cash, world shift, Ranked and game font.
On Join, the host controls shared rules; your font remains personal.
The page is left-aligned, with stacked windows on phones.
