# v0.3.52 — Show the landing player's cash

The previous popup mixed perspectives: it described Yasmina's landing while
showing "Your cash · King Cam" to King Cam. The cash row now follows the player
resolving the landing and explicitly says "Yasmina’s cash" on both screens.
The displayed name, amount and player ID come from the same current server
snapshot. Your own balance remains in Players & Standings.

This applies to property/railroad/utility purchases, cards, rent and bank
payments, paid escapes and turn actions. Settled payments refresh the row.
Authorization still uses the signed-in player; spectators gain no actions.
Arrival gating, money, game rules, artwork and saved matches remain unchanged.

## Install

The Update ZIP supports installed v0.3.46 through v0.3.51 games.
Stop hosting. Extract the v0.3.52 Update ZIP into the existing game folder and
replace matching files. Restart Start-Miniopoly.bat and refresh every player's
browser. Confirm v0.3.52 beside Room. Retain your existing address and browser
data; no room reset or hosting reconfiguration is needed.
