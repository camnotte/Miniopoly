# Left game panel

In Express (World Collapse), the left panel starts with **Game Mode → Express**
and **Building round 1 of 10** (or the current round and chosen limit). Hover
or focus Game Mode to read when collapse starts; tap it on a touch device.
The help reads: “Collapse starts after everyone finishes round 10. Properties
still work normally.” Its round limit follows the actual match. Escape or a
click outside dismisses the explanation.

During the last five building rounds, the existing warning remains visible in
the card. After collapse begins, progress changes to **Collapse · Wave 1** and
the help explains void survival. Countdown uses the same card with its own
progress, rules and each player's remaining properties and shields.

The all-player evade-token strip above the board is removed. Each player's
evade badge remains in Players & Standings, and the landing/turn panel retains
its token information. Click a badge to see the current award and survival rules.

**Trading Center** sits directly under **Chat** in desktop Quick Actions. A
small badge shows the number of incoming offers. It opens the existing trading
window; offers, counteroffers and settlement work as before. Trading is also
available from Game Menu → Properties & trading.

On phones, narrow screens and Full Board View, Game Mode and the trading
shortcut appear in a compact row above the board instead of an offscreen rail.
On a short desktop window, the left panel scrolls so Trading Center stays
reachable. Rules, scores, existing saved games and turn permissions are retained.
