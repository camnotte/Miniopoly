# Miniopoly v0.3.107 — Development wave warnings and the earlier wave artwork

Develop property now marks owned properties in the approaching wave's path with a wave icon, a colored edge and an explicit IN WAVE PATH label. The label separately states whether a built-in shield, a one-wave card or no protection is available. The same indicators appear beside Building Permit choices. The general development guide is collapsed initially to keep these choices and warnings visible. Properties outside the path stay unmarked. Exposure means a property can be selected; it does not claim that every marked property will be hit.

Exposed properties that cannot currently be improved appear in a separate section, with the reason: missing color set, mortgage, full development or a utility. A spent shield carries a warning that building again will not restore it. These indicators follow the announced direction across all neighborhoods, including newly acquired exposed properties, and disappear before sirens reveal a direction or once the ocean is calm.

The illustrated curling crest is replaced by the earlier translucent SVG wave and its original sweep directions. The effect stays inside the board and lasts eight seconds. Demolition, rubble-and-puddle sites, winner receipts and the dismissible personal helper remain in place. Game rules, wave targets, upgrade costs and protection are unchanged. Existing directional matches continue without resetting.
