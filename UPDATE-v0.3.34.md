# Miniopoly v0.3.34 — Compact player cards and shared property overview

The turn panel keeps the larger avatars, full names, shared financial ranks, net worth and cash. The eight property counters move into a separate **Property Overview**. A fanned-card **Properties** button beside each avatar shows total deeds; click it to see everyone's holdings with that player highlighted. Clicking another avatar's button reuses the same window.

The overview has all eight real cross-world set counters. Hover, keyboard-focus or tap a counter for property names, worlds, owners, availability, foreclosures, mortgages and upgrade levels. Completed sets have checkmarks; mortgages still prevent standard upgrades. Owned railroads and utilities have their own details button. The overview is read-only; **Open my detailed portfolio** opens the existing My Properties window for transactions.

On desktop, drag the overview by its heading or focus the heading and use arrow keys (Shift moves farther). Its position is remembered on that browser. The ↺ button resets its position. On phones it becomes a scrollable drawer with four counters per row. Close it with × or Escape; Escape dismisses set details first if open. Game Menu also has **Property overview · All players**. Transaction popups include **View all player properties**, available while waiting for an opponent too. Chat remains on top.

Purchases and sales update the overview on both clients. Ownership and finances retain their existing arrival timing. Selection stays on the chosen player across turns. Leaving a room or finishing a match closes the overview. Nunito, scoring, moving pieces and hosting settings are preserved.

## Install

1. Stop the running game server.
2. Extract **Miniopoly-v0.3.34-Update.zip** and copy all its contents into your existing game folder, replacing matching files.
3. Run **Start-Miniopoly.bat**, choose your usual hosting mode and refresh every player's browser. Confirm **v0.3.34** beside Room.

This cumulative update includes the local and online launchers and their helpers. Keep your existing artwork, HTTPS tool, certificates, hosting settings and saved rooms.

## Review

Click the card-stack button beside either avatar. Confirm all players appear, with the clicked player highlighted. Inspect a set to see who owns missing properties and which worlds contain them. Buy or sell a property and check both clients update. Try dragging, reopening, resetting position, phone scrolling, and using the transaction popup’s overview shortcut while an opponent is making a purchase. The existing My Properties button still opens the detailed portfolio.
