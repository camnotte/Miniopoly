# Miniopoly v0.3.60 — Font options

- [Update ZIP for an existing complete v0.3.59 game](downloads/v0.3.60/Miniopoly-v0.3.60-Update.zip?raw=true).
- [Complete game ZIP](downloads/v0.3.60/Miniopoly-v0.3.60-Complete.zip?raw=true).
- [SHA-256 checksums](downloads/v0.3.60/SHA256SUMS.txt).

If GitHub opens a file page, select Download raw file.
This branch also contains the current v0.3.60 game at its top level, so
Code > Download ZIP supplies the current source and bundled Windows hosting tool.
The main branch has not been changed.

Stop hosting and exit the Game Launcher before updating. Extract the Update ZIP
into the existing v0.3.59 game folder containing server.js and replace matching
files, or extract the Complete ZIP into a new folder and open its
Start-Miniopoly.bat. Start hosting, refresh browsers and confirm v0.3.60 beside Room.

Choose Game Menu > Game Options > Your device > Game font. Nunito and American
Captain are bundled; Apple Chancery is selectable only if that exact font is
installed on the device. Each browser remembers its own choice. Match rules,
player finances and other players' devices are unaffected.

See UPDATE-v0.3.60.md for full behavior, installation and validation details.
