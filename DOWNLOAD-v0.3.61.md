# Miniopoly v0.3.61

- [Cumulative update for a complete v0.3.59 or v0.3.60 game](downloads/v0.3.61/Miniopoly-v0.3.61-Update.zip?raw=true).
- [Complete game ZIP](downloads/v0.3.61/Miniopoly-v0.3.61-Complete.zip?raw=true).
- [SHA-256 checksums](downloads/v0.3.61/SHA256SUMS.txt).

If GitHub opens a file page, select Download raw file. This branch also contains
the current game at its top level: Code > Download ZIP supplies v0.3.61.

Stop hosting and fully Exit Launcher from the Windows system tray before updating.
Extract the update into the folder containing server.js and replace files, or
extract the complete game into a new folder. Start the launcher from that folder,
choose Local Multiplayer, then refresh every browser and confirm v0.3.61.
Reopening the BAT before exiting the old tray launcher can reopen the old game.

Choose Game Menu > Game Options > Your device > Game font. Apple Chancery now has
improved native-font detection and a Check fonts again button. Each browser keeps
its own choice. See [UPDATE-v0.3.61.md](UPDATE-v0.3.61.md) for steps and validation.
