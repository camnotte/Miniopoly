MINI-OPOLY Wi-Fi v0.2.8 — DESIGN LAB PRESET 5

Windows host setup
1. Stop the old Mini-opoly server with Ctrl+C.
2. Extract the new ZIP into a new folder.
3. Double-click start-windows.bat inside this version's folder.
4. Refresh the Windows and Mac browsers (Ctrl+Shift+R / Cmd+Shift+R).
5. Confirm PROTOTYPE v0.2.8 on both screens.
6. Use Restart Test Match to replay with the same persistent room code.
