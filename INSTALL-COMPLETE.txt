MINIOPOLY v0.3.67 - EVADE TOKENS

Stop hosting and fully Exit Launcher from the Windows system tray.
Extract the update into the game folder containing server.js, or extract the
complete package into a new folder. Start the launcher from the updated folder.
Refresh every browser and confirm v0.3.67.

Start a NEW Express / World Collapse match for evade tokens.
Existing saved matches retain their original rules.

1 point per owned property + 1 per upgraded property.
Every 3 points qualifies for 1 token; at least 3 properties required; maximum 3.
The visible count updates during building and locks just before collapse.
A token automatically saves a first landing on a collapsed square.
Returning to that same void is fatal even with tokens left.

Look above the board, on player cards and in landing panels for the token icon.
Click a badge for its breakdown and rule details.
Node.js 18+ is required; no npm install is needed.
See UPDATE-v0.3.67.md and EXPRESS-WORLD-COLLAPSE.md.
