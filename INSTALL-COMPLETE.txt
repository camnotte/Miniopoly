MINIOPOLY v0.3.64 - POLICE CAR AND SCHOOL BUS

Stop hosting and Exit Launcher from the Windows system tray before updating.
Closing the browser or launcher window may leave the old launcher running.
Update ZIP: extract into a complete v0.3.59 through v0.3.63 folder containing
server.js and replace matching files. Complete ZIP: extract into a new folder.
Open Start-Miniopoly.bat from the updated folder and start hosting.
Refresh every browser and confirm v0.3.64. The host must restart to accept the
new School bus selection. Node.js 18+ is required; no npm install is needed.
A Mac host can use start-mac.command; Mac guests use files from the host.

Car is now Police car, preserving saved piece selections. School bus is a new
choice. Both include movement/arrival animations and tire tracks.
Monster truck is not included. Reduced Motion is respected.
Keep your previous installation and private save backup while testing.
See UPDATE-v0.3.64.md for details.
