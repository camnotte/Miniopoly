# Monster truck — design mockup

A design review only. The Miniopoly game is unchanged.

- **Monster-Truck-Motion.gif**: looping motion preview with visible wheel spin,
  suspension bounce and twin fading tire tracks.
- **Monster-Truck-Motion.mp4**: the same preview as a small video.
- **Monster-Truck-Design.png**: full design sheet with moving and parked poses.
- **Monster-Truck-Mockup.html**: interactive standalone mockup. On GitHub, choose
  Download raw file, then open the downloaded HTML in a browser. It embeds its
  artwork and font and does not connect to a game server.
- **Monster-Truck.svg**: parked vector concept.

The interactive version includes Play / Pause, Replay, direction, slow motion,
and a track toggle. Reduced Motion starts the preview paused; Play opts into motion.
The truck uses teal and burnt orange with warm cream highlights. Bold rim spokes,
an orange rim marker and rotating tread blocks make the tires easy to follow.

Checked in Chromium: travel, wheel rotation, suspension motion, tracks, direction
and track toggles, mobile width, and no external asset requests or script errors.
This review adds no game piece, changes no rules or saves, and has no release number.
The actual game files and current working branch remain unchanged.
