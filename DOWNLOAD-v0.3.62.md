# Miniopoly v0.3.62

- [Cumulative update for a complete v0.3.59, v0.3.60 or v0.3.61 installation](downloads/v0.3.62/Miniopoly-v0.3.62-Update.zip?raw=true).
- [Complete game ZIP](downloads/v0.3.62/Miniopoly-v0.3.62-Complete.zip?raw=true).
- [SHA-256 checksums](downloads/v0.3.62/SHA256SUMS.txt).

If GitHub opens a file page, choose Download raw file. This branch also has the
current game at its top level, so Code > Download ZIP supplies v0.3.62.

Stop hosting and Exit Launcher from the Windows tray before updating. Extract
the update into the folder containing server.js and replace files, or extract
the complete ZIP into a new folder. Launch from that folder, start hosting,
refresh every player's browser and confirm v0.3.62.

Pieces use the shoes as their size reference. In Create / Join, the selected
piece previews its animation every two seconds. Reduced Motion is respected.
See [UPDATE-v0.3.62.md](UPDATE-v0.3.62.md) for behavior and validation.
